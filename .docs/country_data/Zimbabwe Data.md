# Data structure

Continent
└── Region
    └── Country
        └── Province
            └── District
                └── Constituency
                    └── Ward
                        └── church-node or local

> Ward-level data added in this pass. Source: Zimbabwe Electoral Commission, *2023 Delimitation Report* (Statutory Instrument 14 of 2023 / Proclamation 1 of 2023), cross-checked against Wikipedia's *List of wards of Zimbabwe* summary for the metropolitan and Manicaland provinces. Wards in Zimbabwe's local government system are numbered per local authority (not individually named like Zambia's wards); each ward below is tagged with the local authority (Rural District Council / Municipality / Town Council / Local Board) that numbers it, since the same number recurs across different authorities. This is administrative census/electoral data, not a legally exact electoral register — per project standard, treat it as "good enough to plant a directory of local congregations against," not a precise boundary reference.
