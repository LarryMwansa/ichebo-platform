# South Africa Data List

# Data structure

Continent
└── Region 
	└── Country 
		└── Province
			└── District
			    └── Constituency
			        └── Ward
                        └── church-node or local


South Africa is data will be interpreted this way

Continent (e.g Africa)
Region (e.g. Southern Africa)
Country (e.g. South Africa)
Province (e.g. Gauteng)
District (Metropolitan municipalities e.g. Nelson Mandela Bay Metropolitan)
Constituency (Local Municipality)
Wards (places under Local Municipality )
local / church-node ( like a church node is that place)

Remember you will notice that there are place with e.g. Dr AB Xuma Local, the "local" there is a designation to indicate where is sits under that municipal structure. In our our name however, we not add the local to that place. That place will be known by the position it takes as a sibling under its parent. 

Remember the designation are for us to know where which parent and child connection are. And to help know where nodes etc exist and their connections.

Once we have the parent places then we can have structure where we can attached other nodes.
