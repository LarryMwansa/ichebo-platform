# Join (Induction) Path

```bash

Public / Seeker → join.ichebo.org (induction surface)
        ↓
Participant → sceptre.ichebo.org (community surface)
        ↓
Steward / Architect → app.ichebo.org (agency surface)

```

## Lessons Direction

What this could look like
join.ichebo.org  — a dedicated subdomain. Publicly accessible. No authentication required to arrive. The surface walks someone through:

- Who the Sceptre Community is and what they are joining
- The invitation acceptance flow
- Account creation — simple, community-framed, not platform-framed
- Pathway selection — which of the eight Kingdom Pathways resonates with them
- The induction programme itself — their first lessons, their first formation steps
- Within the Induction program steps to take have to be made. My thinking scaled down induction and make it automated.
- There has to be steps idea of building the path to getting a user through induction
